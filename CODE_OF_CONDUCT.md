# Code of conduct

JobAgent follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming and respectful, give and accept feedback about the work (not the person), and don't harass anyone. Many people here are students looking for their first job; be the person you'd have wanted to meet.

Report unacceptable behaviour privately to the maintainer through GitHub (Security → Report a vulnerability works for private reports too, or a direct message to the maintainer's GitHub account). Reports are handled confidentially. Maintainers may remove comments, commits or contributions that break this code, and may ban repeat offenders.
