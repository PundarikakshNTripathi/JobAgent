# Resume tailoring (only where it matters)

Tailor only when the role is a strong fit (fit >= 60), a high-stakes target, or the user asks. Otherwise send the closest base variant unchanged.

Rules
- Everything on the tailored resume must be true and already in the profile. Reorder, trim and re-emphasise; never invent a skill, number or employer.
- Mirror the posting's vocabulary only where the candidate really did the thing (e.g. "inference kernels" if they wrote kernels).
- Lead with the 2 or 3 pieces of evidence the posting asks for most. Cut the rest to fit one page.
- Keep one page, same section order as the base resume, and the user's hard rules (things they never want mentioned).
- Output changes as concrete edits (promote / demote / rewrite / add / remove + target + new text + the profile fact that supports it) so the user can apply them to their own resume source.
